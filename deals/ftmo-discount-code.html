Why there is no code

FTMO's affiliate FAQ (source, checked 28 October 2026) says the affiliate code only credits the purchase to the affiliate. It does not lower what you pay. Discounts go in a separate Discount field at checkout.

  • Challenges and Instant Accounts: the affiliate link is what credits the referral. There is no code to type.
  • FTMO Futures: the affiliate code is entered in a separate field at checkout. It credits the affiliate and, per FTMO, does not change the price.
  • Your own code: you can't use your own affiliate code or link for your own purchases.

FTMO can issue its own discount codes through the separate discount field. None is public today. Coupon sites advertise codes such as DGT30 (30%). One such site listed it on 13 October and marked it "paused" on 28 October, and had said on 21 September that FTMO had no public code. That is unofficial and conflicts with FTMO's FAQ, so it is not published here.

The 2-Step fee refund

This is the one official way to get the Challenge fee back. FTMO's entry fee FAQ says it will refund the initial purchase fee once you request your first Reward withdrawal, using the same payment method as the purchase.

The refund means a passed 2-Step can cost you nothing net in fees, but only after you've passed two phases, followed every rule and asked for a withdrawal. It does nothing for attempts that fail. See the FTMO review for the rules.
