How to use a code

  1. Open the firm through the button above. That is how the purchase is credited to us.
  2. Pick your plan and go to checkout. Look for a coupon or code field. If a discount is already applied, there may be nothing to type.
  3. Enter the code and apply it.
  4. Read the total before you pay. If it didn't drop, the code doesn't cover that plan or doesn't stack with a sale. Don't pay extra to chase a code.
  5. Check renewals and refunds. Some plans are monthly subscriptions, and a discount on the first month may not carry over.

Watch out

  • Coupon-farm sites. Pages that list "30% off" codes for every firm often show expired or invented codes, and they contradict each other and the firms themselves. We publish only codes we hold, and we don't repeat third-party codes.
  • Unknown amounts. We can't tell you what LEDGER or A39608C1 are worth. The checkout total is the only proof.
  • A discount is not a reason to buy. A cheaper evaluation is only cheap if you pass and get paid. Most traders fail.
  • Terms change. Codes and sales can end without notice. Each code page has its own check date.
