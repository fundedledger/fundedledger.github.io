How the math works

  1. Static: breach level = starting balance − max drawdown. It never moves. $50,000 − $2,500 = $47,500.
  2. Trailing: breach level = highest level − max drawdown. It moves up when you set a new high and never moves down. $51,500 − $2,500 = $49,000.
  3. Trailing end-of-day: same idea, but the high only counts at the daily close, not intraday.
  4. Lock: if the firm stops the trail at the starting balance, the breach level never goes above it. In this example that is $50,000.
  5. Room left = current balance − breach level.

Exact rules differ. Some firms trail on equity including open trades, some on closed balance, some lock at the start balance, some at start plus a buffer. This tool uses the simple versions above, so confirm with your firm's rules before you size a trade. Not sure which type you have?
